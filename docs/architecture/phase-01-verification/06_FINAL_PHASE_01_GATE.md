## 2. تبرير الحكم بـ «اجتياز مشروط» (Why CONDITIONAL PASS?)

التزاماً بالقاعدة الهندسية الصارمة الواردة في الميثاق:
> *"لا تعلن أبداً الاجتياز التام (PASS) بينما لا تزال اختبارات بيئة التشغيل الحية المطلوبة غير مكتملة أو معلقة (NOT RUN / BLOCKED)"*

وحيث إن:
1. تشغيل واجهات المحاكي بدون نافذة عرض (`-no-window`) واجه انقطاعاً في بروتوكول ADB أثناء الاختبار الثاني.
2. منصة Windows Desktop محجوبة لعدم تثبيت Visual Studio C++ Compiler على بيئة التطوير.

فإن النزاهة الهندسية تقتضي منح **CONDITIONAL PASS**، وهو كافٍ ومفوّض بالكامل تقنياً للانتقال إلى تنفيذ المرحلة 02، مع تسجيل شرط إجراء اختبار دخان يدوي تفاعلي على جهاز أندرويد حقيقي لاحقاً قبل النشر في المتاجر.
